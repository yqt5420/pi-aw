# pi-subagents-cn

**子代理管理（中文界面）**——上游 [pi-subagents](https://github.com/earendil-works/pi-coding-agent) 的汉化版。

## 功能

- 管理 / 配置子代理（subagent）
- 中文配置界面（`/subagents`）、consult / render 等交互文案中文化

## 命令

- `/subagents` — 子代理管理 / 配置

## 维护说明

翻译来自脚本处理上游 `pi-subagents` 文案。上游更新后可用 `scripts/sync-upstream.mjs` + `scripts/translate.mjs` 重新同步+翻译。
