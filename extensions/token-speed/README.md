# token-speed

实时显示 token 生成速度——在每个响应前展示 **TTFT（首个 token 延迟）+ tokens/sec**，完成后显示汇总。

## 功能

- **实时速度**：流式期间底部显示 `⚡ N tok @ X t/s | 首 Xs | 缓NN%`（生成速度 + 首个 token 延迟 + 会话级缓存命中率）。实时速率采用**滑动窗口瞬时效速**（近 ~1.5s 增量），不受起步思考延迟影响，稳定贴近真实速率；token 估算为 **CJK 感知**：中文按 1 字≈1 token，英文按 /4，更贴近真实值
- **完成汇总**：响应结束后显示 `✓ N tok @ X t/s (Ys)`，有精确用量用 `✓`，无精确用量用 `≈` 字符估算兜底
- **缓存命中率**：会话级跨轮累积 `cacheRead`，汇总时显示 ` | 缓NN%`（无缓存数据时自动隐藏，不占显示位）。命中率 = `cacheRead/(cacheRead+input)`，为全会话**近似加权**命中率（每条 assistant message 的 usage 是单次请求完整 input，后续消息叠加会把共享上下文重复计入，故非精确费用值）。**子代理**阶段显示的是主 agent 前序轮次累积值（近似）
- **子代理支持**：`subagent` / `subagent_consult` 运行时显示子代理自身的速度，`⚡ 子代理 [worker] N tok @ X t/s`；汇总同样带缓存命中率。支持并行/嵌套子代理（引用计数），完成汇总行短暂保留防覆盖缝隙
- **自动清除**：汇总展示 5 分钟后自动清空

## 说明

- 本插件的实时/汇总展示依赖 TUI 的 footer status；在**非 TUI**（如 pi-web 等 `!hasUI` 环境）下不展示 footer 标记，子代理阶段也不会显示，属跨端行为差异（功能保持一致，仅展示载体不同）。
- 估算为近似值：非 CJK 生僻字、emoji 等非 BMP 字符会按 /4 回退，属轻微低估。需要精确 token 数以 provider 返回的 `usage` 为准。

## 命令

- `/tokenspeed` — 查看/切换 token 速度显示

无配置文件，零配置即用。
