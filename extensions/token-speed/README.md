# token-speed

实时显示 token 生成速度——在每个响应前展示 **TTFT（首个 token 延迟）+ tokens/sec**，完成后显示汇总。

## 功能

- **实时速度**：流式期间底部显示 `⚡ N tok @ X t/s | 首 Xs`（生成速度 + 首个 token 延迟）
- **完成汇总**：响应结束后显示 `✓ N tok @ X t/s (Ys)`，有精确用量用 `✓`，无精确用量用 `≈` 字符估算兜底
- **缓存命中率**：会话级跨轮累积 `cacheRead`，汇总时显示 ` | 缓NN%`（无缓存数据时自动隐藏，不占显示位）
- **子代理支持**：`subagent` / `subagent_consult` 运行时显示子代理自身的速度，`⚡ 子代理 [worker] N tok @ X t/s`；汇总同样带缓存命中率
- **自动清除**：汇总展示 5 分钟后自动清空

## 命令

- `/tokenspeed` — 查看/切换 token 速度显示

无配置文件，零配置即用。
